# 大学记账 · iOS 可用版

按 `university-budget-app-PRD-v1.0.md` 的 MVP 范围实现，纯前端、零依赖、可离线。

## 怎么在 iPhone 上跑

1. 电脑上执行 `node serve.mjs`（或用任意静态服务器托管这个文件夹）。
2. 手机连**同一个 Wi-Fi**，Safari 打开终端里打印的 `http://192.168.x.x:5178/`。
3. 点分享按钮 → **添加到主屏幕**。

之后从主屏幕图标启动，就是全屏、无浏览器地址栏的独立 App，断网也能记账（Service Worker 缓存了界面）。

> 想在外面也能用，把这个文件夹托管到任意静态站点（GitHub Pages / Vercel / Netlify）即可，代码不用改。

## 口径（与 PRD 6.4 / 10.2 一致）

- 金额一律以**分**为单位整数存储，不出现浮点误差。
- **三餐合计 = 早餐 + 午餐 + 晚餐**；零食单列一行，不算在三餐里，且只统计合计（不算顿数/单均/日均）。
- **餐饮合计 = 三餐 + 零食**，等于「餐饮」分类的支出，在统计页表格下方跟餐饮子预算对账。
- 顿数 = Σ 餐次记录数；单均 = 月总额 ÷ 顿数；日均 = 月总额 ÷ 当月已过天数；顿数为 0 时不显示单均。
- 日均按**当月已过天数**算，月初不失真。
- 预算滚存：宽松（默认，不滚）/ 严格（下月扣超支）/ 结余滚存（下月加上月结余，可设上限）。

## 数据在哪

全部存在浏览器的 `localStorage`（键名 `ubudget.v1`），不上传任何服务器。换设备不会同步；清空浏览器数据会丢。

> 已升级为 `ubudget.v2` + 一份冗余快照 `ubudget.v2.snapshot`。

## 时间与补记

- 每笔记录都带**日期 + 时间**（HH:MM）。新建时默认当前时间。
- 改时间会**自动对上餐次**（05–10 早餐 / 10–15 午餐 / 15–21 晚餐 / 其余零食）；手动点过餐次则不覆盖。
- **忘记记了怎么办**：三处入口都能补
1. 记账页顶部预算条上的 `●早餐 ●午餐 ○晚餐 ○零食` —— 点未记的那一餐，直接带着餐次进记账页；
  2. 明细页每一天右侧的 **＋补记** —— 带着那天的日期进记账页；
  3. 记账页「日期」按钮 —— 手动改成任意过去日期（可回溯 30 天内）。
- 明细行按「时间倒序」排列，同一天里几笔的顺序是真实的先后。

## 记错了怎么办

明细里点任意一笔 → 打开的是**编辑面板**，可以直接改金额、分类、餐次、日期、时间、备注，
不用「删掉重记」。保存后明细、统计、预算条会一起刷新。

## 稳定性做了什么

| 措施 | 解决什么 |
| --- | --- |
| 主数据 + 冗余快照双写 | 主数据损坏时自动从快照恢复，并把主数据修好；**绝不会静默变成空账本**，且会在「我的」页明确告诉你发生过恢复 |
| 完整备份 / 恢复（JSON） | 换网址、换手机、清缓存都能把记录带回来；恢复前自动另存当前数据，可一键撤销 |
| 申请持久化存储 `navigator.storage.persist()` | 降低被系统回收的概率；「我的 → 存储保护」里直接显示当前状态 |
| Service Worker **带超时**的网络优先 | 弱网/校园网卡住时 2.5 秒就切缓存，不再干等；联网后自动拿最新代码 |
| 全局崩溃兜底面板 | 界面真崩了也会弹出一个能**导出备份**的面板，数据不会被困住 |

首次打开会载入 **9/13–9/23 的真实历史记录**（来自流水记录），之后记新的即可。
在「我的 → 数据」里可以清空全部记录，或重新载入这份历史。

### 历史记录的解析口径

笔记里「吃饭 6.5+13+10」这种写法，按 **早餐+午餐+晚餐** 认；
「吃饭 14+13」只有两个数字时，按 **午餐+晚餐** 认（早餐都在 6–8.5 之间，14 不会是早餐）。

- 校园网 50、充校园卡 10 → 归「其他」（本版没有「通讯」分类）
- 短袖 / 卫裤 / 垃圾桶 / 一箱水 / 晾衣架 / 剃须刀 / 生活用品 → 归「生活用品」
- 画材 13.43+36.8+8 → 归「学习」
- 雪糕 3、水果 10、饮料 3.5 → 归「餐饮 · 零食」

笔记最后那行「生活费 545.5」是用户自己对账用的合计，**不是一笔收入**，所以不入账。

核对结果：11 天共 47 笔支出合计 **¥824.60**；
三餐 早餐 ¥54.00(9 顿) / 午餐 ¥148.00(11 顿) / 晚餐 ¥121.80(10 顿)，三餐合计 ¥323.80；零食 ¥16.50(3 笔)，餐饮合计 ¥340.30。

> 9/13–9/19 笔记上的合计是 ¥545.50，与当时明细相加的 ¥602.30 相差 **¥56.80**，正好是 9/19 那笔剃须刀。
> 若剃须刀不算生活费，需要在 App 里删掉这一笔，或改记到别的来源。

## 已知取舍

- 用 PWA 而不是原生 SwiftUI：Windows 上没有 Xcode，无法编译原生 iOS 包。PWA 能装到主屏幕、能离线、性能足够，但不是 App Store 分发的原生应用。
- 推送通知未做：iOS 的 Web 推送需要 16.4+ 且要用户授权，本版只用应用内提示（PRD 3.3 的 70%/90%/100% 提醒以界面状态呈现）。
- 记账提醒、隐私锁、云同步：未实现（FR-08/PRD 5.2 部分）。
